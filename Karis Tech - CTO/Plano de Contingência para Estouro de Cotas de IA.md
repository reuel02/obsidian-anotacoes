# 🛡️ 5d. Plano de Contingência para Estouro de Cotas de IA

### 🎯 Diretriz
Garantir zero paralisação na entrega de sistemas, mesmo em picos de alta demanda de projetos na Karis Tech.

### 🔄 Fluxo de Contingência (Estratégia em 4 Passos)
1. **Nível 1 (Produção Padrão):** Antigravity IDE + Gemini Pro (Custo R$ 0,00).
2. **Nível 2 (Chave de API / Pay-As-You-Go):** Ativação de API no Google AI Studio / Anthropic para pagamento exclusivo por tokens consumidos no pico do projeto.
3. **Nível 3 (Rotatividade de IDEs):** Ativação temporária do Cursor AI Pro (US$ 20/mês) financiado pelo caixa de setup do novo cliente.
4. **Otimização de Código:** Reutilização da biblioteca interna de componentes (`Karis UI Kit`) para economizar janela de contexto.

> **Regra de Margem:** Em projetos de alto volume, o custo extra de APIs/ferramentas não pode ultrapassar 5% do valor da taxa de Setup cobrada do cliente.
