# 🚀 Sistema Coringa (MVP de Demonstração)

> [!abstract] Objetivo do Sistema Coringa
> Um sistema modelo completo, responsivo e altamente funcional que resolve a principal dor do comércio local. Ele serve como ferramenta demonstrativa para reuniões presenciais de vendas (demonstração ao vivo no celular/tablet).

---

## 🛠️ 1. Stack Tecnológica (Código Tradicional)

* **Frontend**: React / Next.js com TypeScript e Tailwind CSS / Vanilla CSS.
* **Backend**: Node.js (Express/Fastify) ou Python (FastAPI/Django).
* **Banco de Dados**: PostgreSQL via **Supabase** (autenticação e banco prontos).
* **Hospedagem**: Vercel (Frontend) + Render / Railway (Backend).

---

## 🎯 2. Funcionalidades Chave do MVP

1. **Gestão Simplificada de Produtos & Estoque**:
   * Cadastro rápido de itens com foto, preço e quantidade em estoque.
   * Alerta de estoque baixo ou esgotado.
2. **Carrinho / Checkout Rápido**:
   * Seleção de produtos pelo vendedor ou cliente final.
   * Cálculo automático de totais.
3. **Integração Nível 1 com WhatsApp**:
   * Botão "Enviar Pedido / Orçamento via WhatsApp".
   * Formatação automática da mensagem com itens, valor total e dados de entrega diretamente para o número do comerciante.

---

## 📱 3. Apresentação em Campo

* **Deploy Ativo**: Aplicação rodando em ambiente de produção com dados fictícios de um comércio real (ex: loja de roupas ou autopeças).
* **Acesso Mobile**: Atalho instalado no celular para simular um app nativo (PWA).
