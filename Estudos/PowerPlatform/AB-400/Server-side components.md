| Option                      | Primary use case                                                   | When to reach for it                                                            | Key limitation                                                                                          |
| --------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **Plug-in**                 | Server-side logic that must run automatically on a Dataverse event | Enforcing a rule on every record change, regardless of caller                   | Requires developer skill. Synchronous steps must stay fast                                              |
| **Custom API**              | An explicit, reusable, intentionally invoked operation             | Multiple callers need one shared contract for the same logic                    | Must be created as an Action to work through the Dataverse connector in a cloud flow                    |
| **Cloud flow**              | Low-code orchestration across connectors                           | A multi-step business process spans several systems                             | Not suited to complex calculations. High volume can hit service limits                                  |
| **Azure Function**          | Custom, code-first compute                                         | A cloud flow's built-in actions can't express the logic needed                  | Code-first with fewer prebuilt connectors. An addition to a cloud flow, not a default                   |
| **Custom connector**        | Wrapping a REST API for low-code triggers and actions              | You already have a usable REST API without a prebuilt connector                 | Needs an OpenAPI 2.0 definition or an exported API collection. OpenAPI 3.0 definitions aren't supported |
| **MCP server**              | A discoverable tool surface shared across agents                   | Several agents need the same tool defined once, centrally                       | Requires generative orchestration in Copilot Studio to consume                                          |
| **Copilot Studio agent**    | Low-code conversational or task agent                              | A conversational assistant needs to reason over a goal and publish to a channel | Capabilities and billing vary by how the agent is configured                                            |
| **Microsoft Foundry agent** | Pro-code, full-control agent hosting                               | Custom orchestration or multi-source logic outgrows a low-code agent            | The hosted, pro-code path adds custom code and compute to maintain                                      |
