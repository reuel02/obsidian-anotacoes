# 🐧 Primeiros Passos: Linux

> *O Linux, em sua essência, é um **Kernel**.*

## 🏗️ Arquitetura do Sistema

Um sistema Linux é dividido em três partes principais:
1. 🖥️ **Hardware**
2. 🧠 **Kernel Linux**
3. 🧑‍💻 **Espaço do Usuário**: Ambiente onde os usuários interagem com o sistema por meio de aplicativos e interfaces de linha de comando (CLI).

---

## 💿 Distribuições (Distros)

Distribuições (ou *distros*) são sistemas operacionais completos criados a partir do kernel Linux. **De modo geral, não existe uma distro "melhor" que todas as outras**, pois cada uma possui uma arquitetura diferente projetada para atender perfis de usuários com objetivos distintos.

Alguns dos principais destaques são:

| Categoria | Distros Recomendadas |
| :--- | :--- |
| 🌱 **Iniciantes** | Ubuntu, Linux Mint |
| 💻 **Desenvolvedores** | Fedora |
| 🧱 **Estabilidade** | Debian |
| ⚙️ **Controle Máximo** | Arch Linux, Gentoo |
| 🏢 **Ambientes Corporativos** | Red Hat Enterprise Linux (RHEL) |
| 🛡️ **Cibersegurança** | Kali Linux, Parrot OS |

> **💡 Resumo:** Cada distro é especialista em um aspecto específico. A escolha ideal depende exclusivamente da sua necessidade e experiência!
